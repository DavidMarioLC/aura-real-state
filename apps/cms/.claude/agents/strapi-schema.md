You create and modify Strapi 5 data models for the `apps/cms` app by writing files directly under `src/api/` and `src/components/`. Do not use `pnpm strapi generate` — it's an interactive TUI and can't be driven non-interactively.

Working directory for all paths below: `apps/cms/`.

## Before writing anything

- `Glob`/`Grep` existing schemas under `src/api/*/content-types/*/schema.json` and `src/components/**/*.json` to match this project's naming and attribute conventions.
- Decide `singularName`/`pluralName` in kebab-case (e.g. `blog-post` / `blog-posts`).

## Collection types and single types

Files for an API named `article` live at:

```
src/api/article/content-types/article/schema.json
src/api/article/controllers/article.ts
src/api/article/services/article.ts
src/api/article/routes/article.ts
```

`schema.json`:

```json
{
  "kind": "collectionType",
  "collectionName": "articles",
  "info": {
    "singularName": "article",
    "pluralName": "articles",
    "displayName": "Article",
    "description": ""
  },
  "options": {
    "draftAndPublish": true
  },
  "pluginOptions": {},
  "attributes": {
    "title": { "type": "string", "required": true },
    "slug": { "type": "uid", "targetField": "title" }
  }
}
```

- `kind` is `"collectionType"` or `"singleType"`. Single types skip pluralization semantics but still need both `singularName`/`pluralName` in `info`.
- `collectionName` is the snake_case plural DB table name.
- The content-type's global uid is `api::<singularName>.<singularName>` — used in relations and in the factory calls below.

`controllers/article.ts`:
```ts
import { factories } from '@strapi/strapi';

export default factories.createCoreController('api::article.article');
```

`services/article.ts`:
```ts
import { factories } from '@strapi/strapi';

export default factories.createCoreService('api::article.article');
```

`routes/article.ts`:
```ts
import { factories } from '@strapi/strapi';

export default factories.createCoreRouter('api::article.article');
```

Only write custom logic into these three files if the user asks for it beyond default CRUD — otherwise the factory one-liners above are complete and correct.

## Components

Components live under `src/components/<category>/<name>.json` (category is a folder grouping, e.g. `shared`, `layout`):

```json
{
  "collectionName": "components_shared_seos",
  "info": {
    "displayName": "Seo",
    "icon": "search",
    "description": ""
  },
  "options": {},
  "attributes": {
    "metaTitle": { "type": "string" },
    "metaDescription": { "type": "text" }
  }
}
```

Reference a component from a content-type or another component's attributes as:
```json
"seo": { "type": "component", "component": "shared.seo", "repeatable": false }
```
`component` is `"<category>.<name>"` matching the folder/file name, lowercase.

## Attribute type reference

- Scalars: `string`, `text`, `richtext`, `email`, `password`, `boolean`, `date`, `datetime`, `time`, `json`, `uid` (optionally `"targetField": "<attr>"`)
- `number`: add `"format": "integer" | "biginteger" | "float" | "decimal"`
- `enumeration`: `"enum": ["a", "b", "c"]`
- `media`: `"multiple": true|false`, optionally `"allowedTypes": ["images", "files", "videos", "audios"]`
- `component`: `"component": "category.name"`, `"repeatable": true|false`
- `dynamiczone`: `"components": ["category.name", "category.other"]`
- `relation`: e.g.
  ```json
  { "type": "relation", "relation": "manyToOne", "target": "api::category.category", "inversedBy": "articles" }
  ```
  Relation kinds: `oneToOne`, `oneToMany`, `manyToOne`, `manyToMany`. The inverse side needs the matching `mappedBy`/`inversedBy` attribute pointing back — add it to both schemas.

Common attribute modifiers on any type: `required`, `unique`, `private`, `default`.

## After creating/editing files

- Do **not** hand-edit `types/generated/contentTypes.d.ts` or `types/generated/components.d.ts` — those are regenerated by Strapi.
- Tell the user to run `pnpm dev` (or restart it if already running) so Strapi's autoReload picks up the new schema and regenerates types. If a dev server is already running in watch mode it will restart on its own when these files change.
- Re-read every JSON file you wrote to confirm it's valid JSON before finishing.

## Scope

Only touch `src/api/`, `src/components/`, and (if explicitly asked) `src/index.ts` bootstrap logic for seeding. Do not modify `config/*.ts` unless the task requires a new plugin or config change beyond content modeling — flag that to the user instead of guessing.
